# FABLE_GAUNTLET_NEXT_STEPS

Ranked. Items 1–2 close gaps the gauntlet measured; the rest are the
natural continuations, all runnable under the same protocol.

1. **Merge + deploy this branch** (user approval). Everything is
   prompt/context/evaluation-layer; rollback is a revert range;
   production risk is low and measured.
2. **Relationship data coverage (F2).** The render-fix only helps
   where `relationships[]` is populated — most real projects have
   empty arrays. Two cheap moves: (a) TV import's character step
   already extracts a cast — extend its schema to emit relationships;
   (b) a Haiku "derive relationships from concept+characters" action
   behind the existing test-mode discipline. Then re-run the Buck Mark
   scene live once (~$0.08) to confirm the wobble dies with data.
3. **Register balance micro-pass (P-B5).** Horror-comedy's comedy
   register came out thin. One contrastive pair in the beats ask
   (dread-only beat vs both-registers beat) + one live retry (~$0.01).
4. **Cosmetic format rule (F3) + climax length (F4).** Two lines in
   the scene/script asks ("plain text only — no markdown markers";
   "climax scenes may run to 500 words"), verified dry-run, folded
   into the next live pass rather than spending calls alone.
5. **Variance characterization.** Each cell ran once. Before trusting
   the gauntlet as a merge-gate, run the 3 scene fixtures twice more
   (~$0.5) to see score spread. Optional; do it the first time a
   future change scores near a threshold.
6. **Cost preview on scriptLoop/easyMode** (carried from Phase 1
   audit): reuse dry-run estimates to show "~$X for N scenes —
   continue?" before the big runs. Small, one confirm dialog.
7. **rewrite_beat / rewrite_highlighted_range pass**: the two
   user-triggered revision asks never got the method; same recipe,
   half a session.
8. **TV surfaces**: episode/pilot asks already carry scene rules;
   run the gauntlet's TV fixture through generate_episode +
   tv_import_pilot with an episode-level rubric.
9. **Judge automation (deferred deliberately):** a Haiku judge that
   scores outputs against the rubrics would make the gauntlet
   re-runnable unattended (~$0.02/output). Worth it the moment the
   gauntlet becomes a routine merge-gate; premature while a human
   reads every output anyway.
10. **Style Lab × gauntlet integration:** run the gauntlet once with a
    locked style profile active to verify voice calibration and craft
    rules compose rather than fight.
