# FABLE_GAUNTLET_RUBRICS

Three gated rubrics for the beats → scene → script chain. Scoring:
0 = absent/violated · 1 = present but weak · 2 = fully landed.
**Any GATE criterion at 0 = automatic FAIL** regardless of total.
Criteria marked (n/a-able) drop from the denominator when the fixture
doesn't exercise them.

Calibration principle (from Phase 2): a rubric that passes a known-bad
output is broken. Known-bads used: the Phase-3 relationship garble
(fidelity gates), the "and then" beat-list pattern, and on-the-nose
dialogue thesis lines.

## BEATS rubric (pass ≥ 10/14, no gate 0)

| # | Criterion | 2 looks like |
|---|---|---|
| B1 | **Causality (GATE)** | Every beat is CAUSED by the one before (but/therefore chain). 0 if two or more "and then" joints — events that merely follow, not force |
| B2 | Escalation | Pressure compounds; a mid-sheet turn changes the problem's nature, not just its size |
| B3 | Final beat | Lands the chosen ending-type's contract with a specific image/act; 0 for a generic "resolution/aftermath" beat |
| B4 | Purpose quality | Each `purpose` names an audience effect ("we realize the money was never real") — not a plot restatement |
| B5 | Specificity | Beat names + summaries use THIS story's nouns; 0 for template names ("The Confrontation", "Things Fall Apart") |
| B6 | **Fidelity (GATE)** | Characters, relationships, and established facts match the bible exactly; no invented principals |
| B7 | Intent | Dials, locked ingredients, snippets, and user direction honored |

## SCENE rubric (pass ≥ 11/16; gates: S1, S2 when purpose set, S7)

| # | Criterion | 2 looks like |
|---|---|---|
| S1 | **Decision or revelation (GATE)** | Something is decided or revealed ON SCREEN; 0 for scenes where people discuss what we already know |
| S2 | **Purpose contract (GATE, n/a-able)** | The beat's stated `purpose` demonstrably happens for the audience |
| S3 | Subtext | Characters say around their wants; 0 when a character states the theme or their need out loud |
| S4 | Voice distinctness | Swap test: no line could move to another speaker unnoticed |
| S5 | Concrete staging | Present-tense, filmable action; specific objects; no "we see", no camera directions |
| S6 | Anti-generic prose | No stock gestures ("a beat of silence", "something shifts", "lets out a breath she didn't know she was holding") or equivalent paraphrases |
| S7 | **Fidelity (GATE)** | Names, relationships, ages, established facts match the bible exactly |
| S8 | Dials + linked moments (n/a-able) | Twist/weirdness dials expressed; linked snippet content genuinely woven in, not name-checked |

## SCRIPT-COHESION rubric (pass ≥ 10/14, no gate 0)

| # | Criterion | 2 looks like |
|---|---|---|
| C1 | **Compounding (GATE)** | Each scene raises the price of the next; no scene resets to neutral; cut points carry charge |
| C2 | Continuity | Facts, objects, injuries, time-of-day survive across scenes |
| C3 | Voice stability | Each character consistent across scenes AND distinct from the others throughout |
| C4 | Beat coverage | Every beat's purpose is landed by its scene (spot-check all; score the weakest) |
| C5 | **Fidelity (GATE)** | Bible facts/relationships correct in every scene |
| C6 | Prose quality | The weakest scene still clears SCENE S3–S6 at ≥1 each |
| C7 | Format | Sluglines + action + CAPS cues consistent; scene lengths inside the ask's bounds |

## Live-round pass thresholds (Phase D)

Per surface: ≥2/3 fixtures pass → surface accepted. One diagnosed
failure → one prompt revision + ≤2 retries (same P3 discipline). The
same failure class twice after revision → stop (design rethink or
routing evidence), per the campaign stop conditions.
