# FABLE_ARCS_RUBRIC

What a good season arc IS, scored the program's way: 0 = absent/
violated · 1 = present but weak · 2 = fully landed. **Any GATE at 0 =
automatic FAIL.** Applies to a generated arc SET (the season plan),
with per-type criteria for individual arcs. Calibrated (per the
Phase-2 method) against the known-weak "before" sample — scored at
the bottom; a rubric that passes it is broken.

## The core principle

An arc is not a vague emotional trend. An arc is **a machine the
episode generator can execute**: it must say what state the season
starts in, what force moves it, what the characters DO about that
force (and why that goes wrong), where it turns, and what is
different on screen at the end. "Jolene learns the cost of power" is
a wish. "Jolene trades her last non-ledger ally (Wade) for a courtroom
win in EP5, and runs the finale with no one left to warn her" is an
arc.

## SET-level rubric (pass ≥ 12/16, no gate 0)

| # | Criterion | 2 looks like |
|---|---|---|
| A1 | **Mechanics in every description (GATE)** | Each arc's description contains startpoint → pressure → what someone DOES (a strategy that fails or costs) → an irreversible turn → endpoint, in this story's nouns. 0 if any arc is a theme-statement or interiority-only ("learns/realizes/discovers/comes to terms") |
| A2 | **Curve grammar (GATE)** | Curves have SHAPE: valleys after peaks, quiet setup episodes, at least one arc that front-loads or mid-peaks. 0 if ≥2 arcs are monotonic ramps, or if all arcs peak on the same episode |
| A3 | Peak staggering / episode identity | Each episode has a different dominant-arc mix; the season's "which arc owns this hour" answer changes week to week. No episode carries >8 arcs at ≥6 (the engine's overload line) except a deliberate convergence episode — and then ONLY one |
| A4 | **Moments as turns (GATE)** | Every major arc anchors 1–3 hard moments to specific episodes, and each is a turn/reveal/choice/consequence — filmable, not "things intensify" |
| A5 | Relationship coverage | Loaded dyads in the cast's FIXED-FACTS relationships produce at least one relationship-type arc naming its pair; the collision is specific (what event re-prices the bond) |
| A6 | **Fidelity (GATE)** | Arcs use only bible characters/facts; guardrails honored (nothing an arc plans contradicts must-preserve / do-not-turn-into); no invented principals |
| A7 | Type honesty | Types match content (a moral descent isn't labeled "character" for convenience); the set uses the roster's expressive range where the material supports it (secrecy, power, investigation…), not just character+subplot+theme |
| A8 | Convergence design | At least one planned episode where 2+ arcs collide ON PURPOSE, stated in a description or moment ("EP5: Dray's hunt exposes Clay's signature") — collisions are where episodes come from |

## Per-type criteria (each scored inside A1 when that type appears)

1. **Main plot** — names the concrete contested OBJECT/QUESTION
   (the ledger, the file, the body), who wants it, the escalation
   pattern (what each round costs more of), and the endpoint state.
   Not "the siblings battle over X" but ROUNDS of the battle.
2. **Character** — behavior change, not inner growth: the description
   names an ACT the character performs late-season that they refuse /
   cannot perform in EP1, plus the false strategy they burn first.
   Ban-class: "learns to accept/believe/comes to terms/finds himself".
3. **Relationship** — names BOTH characters and the bond's starting
   contract, the event that re-prices it, and the new contract at
   season's end. The dyad must collide with at least one other arc.
4. **Mystery / reveal** — the reveal LADDER: what the audience knows
   at start, 2–3 stepped reveals (each re-framing, not just adding),
   and what must NOT surface before its step ("no earlier than EP6").
5. **Moral descent** — the RUNG structure: each rung is a choice that
   would have been refused one rung earlier, with a witness who
   clocks it; the description names the first rung and the point of
   no return.
6. **Theme** — must be CARRIED: a recurring concrete object, ritual,
   or transaction embodies the question (the ledger page changing
   hands; the reservoir line dropping). 0 if the description reads as
   an essay ("the season explores…").
7. **Subplot** — earns its screen time: states what it FORCES into
   the main plot (proximity, deadline, resource drain) and which
   episode range it owns; a subplot that never touches another arc
   is dead weight.

## What should NOT happen too early (checked under A4/A8)

Reveals before their ladder step; the irreversible choice before the
false strategy has visibly failed; relationship ruptures before the
bond's value is established on screen; finale-stakes intensity (9–10)
before the midpoint except as a deliberate cold-open spike.
